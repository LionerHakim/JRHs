# JRHs — Personal Digital Portfolio

Personal digital portfolio for JRH.

## Stack

- React 19
- TypeScript
- Vite
- CSS
- Cloudflare Pages

## Development

`npm install`
`npm run dev`

## Verification

`npm run typecheck`
`npm run build`

## Deployment

Framework: Vite  
Build command: `npm run build`  
Output: `dist`  
Node.js: 22

Portfolio content is centralized in `src/config/site.ts`.

Production site: https://jrhsee.my.id/
