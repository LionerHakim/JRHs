# Security Policy

## Supported Version

The `main` branch is the supported version of JRHs.

## Reporting a Vulnerability

Do not disclose suspected security vulnerabilities publicly before the issue is assessed.

Please use GitHub's private vulnerability reporting flow for this repository when available. Include reproduction steps, affected files or routes, impact, and any relevant logs.

Do not include passwords, access tokens, API keys, private personal data, or other secrets in a report.
